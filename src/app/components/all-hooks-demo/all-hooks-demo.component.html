What You're Seeing

🔄 Frequent Hooks

ngDoCheck, ngAfterContentChecked, and ngAfterViewChecked run on every change detection cycle. Notice how often they're called!

🚀 Initialization Hooks

ngOnInit, ngAfterContentInit, and ngAfterViewInit run only once when the component is first created.

📥 Input Changes

ngOnChanges is triggered when @Input() properties change. Try modifying the input values above.

🧹 Cleanup

ngOnDestroy runs when the component is destroyed. Toggle the child component visibility to see it in action.
