Key Points About ngOnChanges

  • When it runs: Called whenever one or more @Input() properties change
  • First change: The firstChange flag indicates if this is the initial value
  • Change detection: Only detects changes in object references, not deep property changes
  • SimpleChanges: Provides currentValue, previousValue, and firstChange for each changed property
  • Use cases: Input validation, derived property calculation, side effects on input changes
