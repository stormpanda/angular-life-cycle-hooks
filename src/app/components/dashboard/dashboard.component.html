🔄 Frequent Hooks

ngDoCheck, ngAfterContentChecked, and ngAfterViewChecked run on every change detection cycle. Use them carefully!

🏁 One-time Hooks

ngOnInit, ngAfterContentInit, and ngAfterViewInit run only once per component instance.

🧹 Cleanup

Always use ngOnDestroy to unsubscribe from observables and clean up resources to prevent memory leaks.
